# МетабоСкан для Encore: путь клиента

Кликабельный прототип пути клиента Encore в рамке телефона: заказ, анкета, выезд медсестры, статусы в личном кабинете, результаты и сообщения, которые клиент получает по дороге.

Адрес: https://slnkt.github.io/encore-metaboscan-flow/

## Как устроено

- Статика без сборки: `index.html`, `assets/styles.css`, `assets/app.js`.
- Весь контент в `data.js`: шаги, тексты экранов, анкета, слоты, коммуникации.
- Результаты анализов берутся из `assets/metaboscan_sample_results.json` (тестовые данные). Статус показателя считается по Z: меньше 1,3 в норме, от 1,3 до 2 пограничный сдвиг, от 2 выраженный сдвиг.
- Незаполненное пишется как `"[ЗАПОЛНИТЬ: что именно]"` и выводится заметной плашкой.

## Как добавить или убрать сообщение

В `data.js` в массиве `comms` одна строка на сообщение:

```js
{ after: "confirmed", moment: "Накануне забора", format: "sms", subject: "", text: "Текст" }
```

- `after` — id экрана из `screens`, после которого приходит сообщение.
- `format` — `email`, `push` или `sms`.
- `attachment` — подпись вложения для письма, если оно есть.

Верстку менять не нужно, шаг появится в списке сам.

## Пример отчета

Пациентский отчет кладем в `assets/` только после подтверждения, что данные в нем тестовые. Затем в `data.js` указать `reportPdf: "assets/metaboscan_example_krov_patient.pdf"`.
