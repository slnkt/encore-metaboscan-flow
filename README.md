# МетабоСкан для Encore: путь клиента

Кликабельный прототип пути клиента Encore в рамке телефона: заказ, анкета, выезд медсестры, статусы в личном кабинете, результаты и сообщения, которые клиент получает по дороге.

Адрес: https://slnkt.github.io/encore-metaboscan-flow/

## Как устроено

- Статика без сборки: `index.html`, `assets/styles.css`, `assets/app.js`.
- Весь контент в `data.js`. Путь клиента — массив `steps`: экраны, SMS и письмо по порядку, номер шага считается сам.
- У каждого шага `roles` — блок «Кто что делает» (Клиент, Encore, Bioniq, Сеченовский университет).
- Результаты анализов берутся из `assets/metaboscan_sample_results.json` (тестовые данные). Статус показателя считается по Z: меньше 1,3 в норме, от 1,3 до 2 пограничный сдвиг, от 2 выраженный сдвиг.
- Плейсхолдеров в квадратных скобках на сайте нет: пустое поле просто не выводится.

## Как добавить или убрать сообщение

Добавьте или удалите элемент в `steps` в нужном месте пути:

```js
{ type: "sms", stage: "Сдача", title: "SMS: накануне", sender: "Bioniq", text: "Текст", day: "eve", time: "19:00",
  roles: [["bioniq", "Напоминает о записи"]] }
```

- `type` — `sms` или `email` (для письма еще `subject` и `attachment`).
- `day` — день на экране блокировки: `today`, `eve` (накануне сдачи), `visit` (день сдачи), `results` (день результатов).
- Пустой `text` — баннер без текста.

Верстку менять не нужно.

## Пример отчета

Пациентский отчет кладем в `assets/` только после подтверждения, что данные в нем тестовые. Затем в `data.js` указать `reportPdf: "assets/metaboscan_example_krov_patient.pdf"`. Пока файла нет, кнопка «Скачать PDF» ничего не открывает.
